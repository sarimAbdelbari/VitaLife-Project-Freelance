## 🚑 Project Overview

This website serves as a digital front door for the Centre Diagnostic, showcasing its medical services, sharing information about the clinic, and making it easy for patients to find contact details and location.

Key goals:
- Build trust and credibility
- Present services clearly
- Enable easy appointment booking
- Highlight location and contact info

---

## ✨ Features

- 🏥 **Hero Section:** Engaging welcome with clinic name, tagline, and call-to-action.
- 📖 **About Us:** Short introduction to the Centre's mission and values.
- 💉 **Services Section:** Clear cards or grid listing all medical services.
- 💙 **Why Choose Us:** Highlights of the Centre's advantages.
- 🗣️ **Testimonials:** (Optional) Patient stories for trust-building.
- 📍 **Contact & Map:** Address, phone, email, working hours with integrated Google Maps.
- 📱 **Fully Responsive:** Works on desktop, tablet, and mobile.
- ⚡ **Modern Design:** Clean UI, smooth scroll, subtle animations.

---

## 🛠️ Tech Stack

- **Next.js 15** - React framework with App Router
- **TailwindCSS 4** - Utility-first CSS framework
- **Framer Motion** - Advanced animations and interactions
- **Google Maps Embed** - Interactive map integration
- **Responsive Design** - Mobile-first approach
